# Apex Strength Club

A modern fitness website built with Next.js, TypeScript, and Tailwind CSS.

## Features

* Responsive design
* Modern dark theme
* Membership plans
* Training programs
* Trainer profiles
* Testimonials
* FAQ section
* Contact section
* Mobile-friendly UI

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* shadcn/ui
* Vercel Analytics
